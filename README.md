# LLM Pipeline Explorer

A beginner-friendly, interactive page for exploring how language models process text.

## What you can explore

- Build a vocabulary and tokenize sentences.
- Compare spelling-based and meaning-based sentence embeddings.
- View sentence embeddings in a 3D chart and find similar sentences.
- Add your own sentence to the chart.

## Run it

Open `index.html` in a browser. Plotly.js and the meaning-based model load from online CDNs, so those features need an internet connection.
